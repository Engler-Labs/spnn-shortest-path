# spnn-shortest-path

Reference implementation, data, and figures for the paper on **stochastic spiking
neural networks for shortest-path computation** — a graph is compiled into
winner-take-all neuron clusters whose Boltzmann energy minima coincide with
shortest paths, run as a discrete-time Boltzmann sampler, and the path is read
out of the induced subgraph. A single sampling step costs **O(|E|)** instead of
O(N·d²).

This repository is the reproducibility artifact: `CLAIMS.tsv` lists one row per
printed number in the paper, and every number is regenerated by a script here and
checked against a committed output.

- **What the results say:** [`FINDINGS.md`](FINDINGS.md)
- **How reproduction works** (tiers, labels, cost, disclosures): [`REPRODUCIBILITY.md`](REPRODUCIBILITY.md)
- **The claim table:** [`CLAIMS.tsv`](CLAIMS.tsv)

## Install

```bash
pip install -e .          # installs the `spnn` library (numpy + scipy)
```

## Reproduce

```bash
python -m verify              # Tier-1: exact/deterministic checks + the CLAIMS.tsv audit
python -m verify --full       # also the seeded/expensive contrast variants

python -m experiments list    # the experiment catalog (one per claim group)
python -m experiments 7       # run one experiment by id
python -m experiments all     # every built Tier-1 experiment (--full adds Tier-2)
```

Each experiment writes its committed output under `results/` and prints its own
comparison against `CLAIMS.tsv`.

## Layout

```
spnn/            the library
  compile.py       graph -> segment-structured spiking network (Params, Network)
  sim.py           the O(|E|) sampler, energies, induced-subgraph readout
  graphs.py        graph generators + Dijkstra
  counting.py      exact path / matching-polynomial / scatter counters (overflow-guarded)
  yen.py           Yen's k-shortest loopless paths (the optimality gap)
  validate.py      the three correctness checks (decomposition, Boltzmann, end-to-end)
  bench.py         O(|E|) vs sparse-spmv scaling
experiments/     one module per CLAIMS row group; run by id via `python -m experiments`
verify/          check_a/b/c + check_claims — the acceptance layer
figures/         figure-coordinate emitters (e.g. fig_creq)
instances/       the pinned reference instance + population manifest
results/         committed outputs (the number-by-number diff target)
CLAIMS.tsv       every printed number, its script, output, tolerance, and label
```
